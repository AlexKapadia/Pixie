## Get started in seconds

Clone the repo and you're off — the copy button is on the right.

```bash frame="terminal" title="Clone Pixie"
git clone https://github.com/AlexKapadia/Pixie.git
```

Then follow [Install & first run](/Pixie/start/install/) for `uv sync` and launching the dashboard.

## One dashboard. Every tool you've ever written.

Pixie is a single local web app that scans a `tools/` folder, lists every tool
it finds in a sidebar, and renders a schema-driven UI for each one. Each tool
runs in its own isolated `uv` virtual environment as a subprocess that spins up
on click and shuts down when idle.

You don't install tools through the UI. You add them in Claude Code with one
of the shipped skills, and they appear in the sidebar after the validator
confirms the contract is honoured.

## Add a tool in one sentence

```text title="In Claude Code"
Add a Pixie tool that converts currencies using the Frankfurter API
```

That sentence triggers the `add-tool-from-description` skill, which:

1. Picks a kebab-case `id` and a human-readable name.
2. Writes `tool.json` with a `select` for the source currency, another for the
   target, a `number` for the amount, and an output `number` formatted as
   currency.
3. Writes `pyproject.toml` and `main.py` (a FastAPI app honouring the
   `/schema` + `/healthz` + `/run` contract).
4. Runs `uv sync` to build the `.venv`.
5. Runs `uv run pixie validate currency-converter` — 11 checks, including
   spawning the tool and POSTing sample input.
6. Surfaces the full report. Only if `overall: pass` does it claim success.

Refresh the dashboard and the tool appears in the sidebar with a green dot.

## What Pixie is not

Pixie is not hosted, not a SaaS, not a marketplace, not a deployment platform.
It does not authenticate users. It does not synchronise to the cloud. It is
not a generic app platform — it is for small tools and models with simple
input/output contracts.

Pixie does not ingest, install, or modify tools from inside its own UI.
Adding tools is done externally in Claude Code using the skills shipped in
this repo. From Pixie's perspective, tools simply appear on disk in the
`tools/` folder and it renders whatever is there.
